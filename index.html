Tentang Project

Dari File Terpisah ke Satu Workbook

Pipeline ini menangani pekerjaan konsolidasi berulang: membaca beberapa format sumber, menyatukan kolom yang sepadan, menormalkan tanggal, menerapkan filter periode, dan menyiapkan Excel untuk pemeriksaan lanjutan. File sumber operasional tidak disertakan dalam portfolio.

CSVExcelZIP berisi CSVDatetimeData QualityExcel Export

Multi-format Import

Membaca CSV, semua sheet dalam workbook Excel, dan file CSV yang ada di dalam ZIP.

Data Consolidation

Menyeragamkan nama kolom lalu menggabungkan tabel dengan skema yang tidak selalu sama.

Date Handling

Mencoba format tanggal yang dikonfigurasi; tanggal yang gagal dibaca ditandai sebagai tidak valid.

Period Filter

Menghapus tanggal tidak valid, menerapkan batas tanggal inklusif, lalu mengurutkan data.

Excel Workbook

Membuat ringkasan, memisahkan sheet menurut bulan, serta menambahkan filter dan freeze header.

Safe Portfolio Demo

File contoh berisi label generik yang dibuat khusus; tidak ada log atau identitas operasional.

Batas & Keamanan

Gunakan data yang memang boleh diproses dan dibagikan. Portfolio ini tidak menyertakan nama perusahaan, host, IP, aplikasi, atau file sumber operasional.

  • ZIP membaca file CSV di dalam arsip.
  • Tanggal invalid dibuang; tanggal duplikat tidak otomatis dihapus.
  • Rentang tanggal diatur di python/config.py.
